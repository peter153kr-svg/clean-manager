# 맑은하늘클린 AI 오피스 구현 로드맵

## 역할

하나의 작업 엔진 아래 **AI 총괄실장 1명 + 전문 직원 8명**을 운영합니다.
각 '직원'은 별도의 유료 상시 모델 세션이 아니라, 업무별 프롬프트·규칙·도구 권한과 작업 큐를 가진 실행 역할입니다.
이벤트가 있을 때만 실행하여 API 토큰과 운영비를 통제합니다.

| 역할 | 입력 | 결과 | 최종 승인 |
| --- | --- | --- | --- |
| AI 총괄실장 | 모든 업무 큐, CRM KPI | 우선순위·일일 브리핑·누락 점검 | 중요 변경 |
| 1. 일정 비서 | 텔레그램 채널 원문, CRM 작업 | 날짜·현장·인원 추출, 충돌 확인, 출발 전 브리핑 | 일정 확정·변경 |
| 2. 매출·정산 | CRM 작업/매출/예약금 | 일·월 매출, 미수금, 목표 대비 실적 | 청구·수납 변경 |
| 3. 문의·견적 | 홈페이지 문의, 고객 정보, 가격 규칙 | 필요한 확인 질문, 견적 초안, 예약금 안내 | 견적 발송 |
| 4. 블로그 SEO | 완료 현장·사진·스토리, 검색 데이터 | 키워드 후보와 근거, 블로그 원고·사진 순서 | 발행 |
| 5. 현장 자료 담당 | 현장 사진·영상·음성·메모 | 촬영물 정리, 전후 비교, 작업 사실 검증 | 대외 사용 |
| 6. 릴스 기획 | 예정 현장·창 구조·과거 성과 | 현장 출발 전 후킹·컷리스트·촬영 체크리스트 | 촬영 방향 |
| 7. 영상 편집 | 수집된 현장 영상 | 9:16 편집·자막·BGM 라이선스 검토·검수 파일 | 최종 승인 |
| 8. 채널 운영 | 승인된 블로그·릴스·현장 이야기 | 스레드 초안, 인스타/틱톡/유튜브별 게시 패키지 | 게시 |

## 이벤트 중심 흐름

1. 외부 시스템(텔레그램, 홈페이지, 미디어 업로드)이 수신함에 원본 이벤트를 기록합니다.
2. 정규화 단계가 날짜·현장·비용·의도를 추출하고 불확실성을 표시합니다.
3. 작업 큐가 해당 직원 역할에만 작업을 배정합니다. 긴 작업은 재시도·실패 기록을 남깁니다.
4. 총괄실장이 충돌·중복·원본과의 불일치를 검사합니다.
5. 대표님이 중요 작업을 승인하면 외부 게시·전송 작업이 실행됩니다.
6. CRM 분석 화면에서 업무 상태, 작업당 AI 비용, 전환율을 확인합니다.

## 단계적 출시

- **1단계 (현재 PR):** 텔레그램 채널 새 게시글·수정본 안전 수집, CRM 원문·이력 화면. 기존 업무/매출 데이터 변경 없음.
- **2단계:** 대표님 실제 메시지 예시를 바탕으로 일정·가격·현장 파서와 신뢰도/검토 화면 개발. 승인 시에만 기존 `jobs`와 연결.
- **3단계:** 일정 비서 + 매출·정산 + 총괄실장 일일 보고, 텔레그램 지시/회신 분리. 읽기/쓰기 명령 권한 검증.
- **4단계:** 완료 현장의 자료 수집 → 블로그 SEO 초안·사진 배치 → 릴스 촬영 체크리스트.
- **5단계:** 영상 편집 및 플랫폼별 업로드 준비, 스레드 초안, 콘텐츠 승인 화면.
- **6단계:** 업무 큐 복구·알림·실패 재시도, 추적 로그, 모델 호출 한도, 비용 상한, 자동화 품질 평가.

## 외부 플랫폼 제약

- 네이버 블로그의 네이티브 임시저장/발행은 일반적인 공식 쓰기 API로 보장되지 않습니다. 먼저 CRM 안에서 사진과 함께 발행 전 초안을 완성합니다. 브라우저 자동화 방식은 별도 검증·허가가 필요합니다.
- 인스타그램의 앱 내 임시저장은 일반적인 콘텐츠 게시 API의 공개 기능과 동일하지 않습니다. 지원되는 예약 게시/승인 워크플로를 우선 설계합니다.
- 영상 원본, 음악 라이선스, 얼굴·주소·차량번호 등 개인정보에 대한 자동 검수가 필요합니다.
- 견적 금액과 일정은 초안만 자동화하고, 대외 전송·예약 확정·게시 전에는 사람 승인을 기본으로 둡니다.
